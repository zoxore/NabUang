# 💰 NabUang

A personal finance management app for tracking wallets, transactions, bills, and spending.

Built with Flutter and Firebase.

## ✨ Technologies

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Riverpod
- GoRouter
- FL Chart

## 🚀 Features

- 💰 Manage multiple wallets
- 💸 Track income and expenses
- 🔄 Transfer money between wallets
- 🧾 Manage bills and payments
- 🏷️ Create and manage transaction categories
- 📊 View financial reports and spending breakdowns
- 🔐 Email, Google, and Guest authentication
- ☁️ Cloud data synchronization
- 🌙 Light and dark mode

## 🛠️ The Process

NabUang was built as a personal finance management app focused on making everyday money tracking simple and easy to understand.

The project was developed with Flutter and uses Firebase Authentication and Cloud Firestore for user authentication and cloud data storage. Riverpod is used for state management, while GoRouter handles navigation between screens.

The app is structured around wallets, transactions, bills, and categories, with financial reports to help users understand their spending.
